2. Lõi Tính Sát Thương & Lượt Boss Match-3 (Match3CombatRules.cs)

Lớp C# thuần (không dùng UnityEngine), quyết định toàn bộ cân bằng chiến đấu và dễ viết Unit Test.

Scripts/Guardian/Match3/Core/Match3CombatRules.csPure C#
public StepResult ApplyStep(CascadeStep step) {
    float mult = MultiplierFor(step); // Combo + Match >= 4
    result.Damage = Scale(
        step.SwordCount * m_Config.DmgPerSword +
        step.PurifyCount * m_Config.PurifyDmgPerTile, mult);

    PlayerShield = Math.Min(m_Config.PlayerMaxShield,
        PlayerShield + Scale(step.ShieldCount * m_Config.ShieldPerTile, mult));
    PlayerEnergy = Math.Min(m_Config.PlayerMaxEnergy,
        PlayerEnergy + step.EnergyCount * m_Config.EnergyPerTile);

    int reduce = Math.Min(BossIntent,
        Scale(step.PurifyCount * m_Config.PurifyIntentPerTile, mult));
    BossIntent -= reduce;
    DamageBoss(result.Damage);
}

public BossTurnResult ResolveBossTurn() {
    result.Blocked = Math.Min(PlayerShield, BossIntent);
    result.Damage = BossIntent - result.Blocked;
    PlayerShield = 0; // Giáp chỉ đỡ đòn của lượt này
    PlayerHp = Math.Max(0, PlayerHp - result.Damage);
    if (PlayerHp <= 0) Outcome = CombatOutcome.Defeat;
    else RollIntent();
}

Giải thích từng bước

ApplyStepHệ số nhân Combo: Mỗi đợt ngọc rơi nối tiếp (CascadeStep) tăng thêm +0.25x (tối đa 2.0x), nếu ăn dây 4+ viên nhân thêm 1.5x.
PurifyCơ chế Khắc chế Boss: Viên Purify vừa gây sát thương nhẹ vừa trừ thẳng vào BossIntent (sát thương Boss sắp tung ra ở cuối lượt).
ResolveBossTurnQuy tắc Giáp (Shield): Giáp chặn trước, phần dư trừ vào Máu. Sau đòn đánh, PlayerShield về 0 (buộc người chơi liên tục ăn Khiên mỗi lượt nếu muốn phòng thủ), rồi Boss bốc Intent mới (mỗi 3 lượt tụ lực ×1.6).

Giải thích từng bước

Outbox JSONBền vững khi tắt app: Mọi event đều được ghi xuống guardian_outbox.json trước khi gửi. Nếu mất mạng, nó tăng thời gian chờ theo cấp số nhân (2s → 4s → 8s...) và gửi lại sau.
IdempotencyChống ghi trùng ở Server: Client gửi kèm UUID event_id. Nếu mạng lag khiến client gửi lại cùng event đó, Server kiểm tra SQLite và trả 200 duplicate (hoặc 409 conflict nếu payload khác), client coi như đã sync xong và xóa khỏi hàng đợi.
Sync WorkerĐẩy Cloud tách riêng: API trả kết quả cho Unity ngay lập tức, còn việc gọi Adafruit IO do container iuh-guardian-sync chạy ngầm xử lý.

for (int i = 0; i < t.Length; i += 3) {
    Vector3 a = world[t[i]], b = world[t[i+1]], c = world[t[i+2]];
    var n = Vector3.Cross(b - a, c - a);

}

11. NPC Tuần Tra & Sinh Viên Sân Trường (NPCMovement.cs)

Điều khiển NPC đi theo tuyến NPCRoute qua NavMesh hoặc tự di chuyển fallback khi không có NavMesh.

Scripts/NPC/NPCMovement.csC#
if (m_Agent != null && m_Agent.isActiveAndEnabled && m_Agent.isOnNavMesh) {
    if (!m_Agent.pathPending && m_Agent.remainingDistance <= arrivalThreshold)
        OnArrivedAtWaypoint(targetWp);
} else {
    // Fallback khi khu vực chưa bake NavMesh
    Vector3 dir = targetWp.transform.position - transform.position; dir.y = 0;
    if (dir.magnitude > arrivalThreshold) {
        transform.position += dir.normalized * moveSpeed * Time.deltaTime;
        transform.rotation = Quaternion.Slerp(transform.rotation, Quaternion.LookRotation(dir), 8f * Time.deltaTime);
    } else OnArrivedAtWaypoint(targetWp);
}
